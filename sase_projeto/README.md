# SASE - Sistema de Atendimento por Senha Eletrônica

Projeto para a disciplina de Sistemas Distribuídos - IFCE Campus Crato.

## Como Executar
1. Inicie o servidor: `python servidor/srv_main.py`
2. Inicie o terminal de exibição: `python terminais/tv_terminal.py` 
3. Use o terminal de senhas para gerar requisições: `python terminais/ts_terminal.py`
4. Chame os atendimentos usando o terminal de atendimento: `python terminais/ta_terminal.py`
